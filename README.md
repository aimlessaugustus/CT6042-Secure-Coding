# CT6042-Secure-Coding

## Overview

Repository for the Secure Coding module at university. This repository consists of the following areas:

- Lecture Notes: Notes created during the university block week (Not intended for Assignment Review).
  
- Lecture Code: Code from the practical exercises on Moodle (Not intended for assignment Review)

- Assignment Notes and Code: Notes created during the assignment process and the assignment code itself. The notes are intended to be a more complete, less abridged version of the assignment sections to provide an overview of the implementation, underlying theory and criticality that took place as part of the learning process.
