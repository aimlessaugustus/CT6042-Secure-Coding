# CT6042-Secure-Coding

## Overview

Repository for the Secure Coding module at university. This repository consists of the following areas:

- Lecture Notes: Notes created during the university block week (Not intended for Assignment Review).
- Assignment Notes: Notes created during the assignment process, intended to be an appendix to the assignment itself to show the raw thinking and planning process.
- Assignment Code: The actual code for the assignment, with automated testing implementations to demonstrate secure coding vulnerabilities.
